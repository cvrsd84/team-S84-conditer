# Кондитерская Александра

Трёхмерный симулятор кондитера для Windows. Проект Unity 6.3 LTS находится в папке [ConfectioneryAlexandra](ConfectioneryAlexandra).

[Скачать версию 1.0 для Windows](https://github.com/cvrsd84/team-S84-conditer/releases/tag/v1.0) — первые два играбельных дня.

В текущей ветке после обучения доступны рабочие смены с автоматической выдачей заказов, семью рецептами и отчётом по итогам дня.
